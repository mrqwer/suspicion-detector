# Система обнаружения вторжений в зоны ограниченного доступа

Проект для отслеживания людей в определённых зонах на видео и предупреждать, если кто-то нарушает границы. Она использует YOLOv8 для детекции и трекинга людей, а также позволяет интерактивно задавать запретные зоны на видео.

---

## Возможности

- Детекция людей на видео с использованием YOLOv8.
- Опциональный трекинг людей с сохранением `track_id` для отслеживания каждого объекта между кадрами.
- Проверка пересечения людей с заранее заданными запретными зонами.
- Визуализация:
  - Красные тонкие полигоны — запретные зоны
  - Синие прямоугольники — обнаруженные люди
  - Красные толстые — нарушители зоны
  - Индикация активной тревоги на экране
- Интерактивное создание зон с помощью мышки.
- Поддержка CPU и GPU (CUDA) для инференса.

# Использование
## Запуск скрипта
```bash
python main.py --video path/to/video.mp4
```
### 
- `--video` - путь к видео (обязательный аргумент)
- `--model` - путь к файлу модели YOLO(по умолчанию yolov8n.pt)
- `--zones` - путь к файлу с зонами (по умолчанию restricted_zones.json) 
- `--device` - устройство для инференса (cpu или cuda)
- `--no_tracking` - отключить трекинг людей 

Пример с пользовательскими аргументами:
```bash
python main.py --video test.mp4 --device cuda --zones my_zones.json
```
# Создание запретных зон
Если файла зон нет или хотите создать новые зоны: 
1. Скрипт автоматически предложит создать зоны при первом запуске. 
2. Вы увидите окно с первым кадром видео. 
3. ЛКМ — добавление точек полигона. 
4. s — сохранить текущую зону. 
5. q — выйти без сохранения. 
Минимум 3 точки, чтобы зона считалась валидной.

# Как это работает 
1. HumanDetector — детектирует людей на кадре, а при включенном трекинге присваивает каждому уникальный track_id. 
2. ZoneHandler — хранит зоны, рисует их на кадре и проверяет пересечение с bounding box’ами людей. 
3. AlarmHandler — управляет сигналом тревоги и отображением тревожного индикатора. 
4. VideoProcessor — объединяет всё вместе: читает видео, вызывает детекцию/трекинг, проверяет зоны, рисует результат и тревогу на кадре.
